# AWS Certified Cloud Practitioner（CLF-C02）- 学习大纲

> 事实核对时间（对照 AWS 官方文档）：2026-08-19

## 考试概览

CLF-C02 考试验证对 AWS 云概念、服务、安全、架构、定价和支持的基础理解。它面向希望展示 AWS 云整体知识的人士，不限具体技术角色。

- **格式**：65 题（50 计分 + 15 不计分），单选和多选。
- **时长**：90 分钟（非英语考试加时 30 分钟）。
- **计分**：缩放分数 100-1,000；最低通过分数 700；补偿计分。
- **建议经验**：6 个月的基础 AWS 云与行业知识。

## 内容领域

官方考试指南定义了四个内容领域及其权重：

1. 云概念（24%）。
2. 安全与合规（30%）。
3. 云技术与服务（34%）。
4. 账单、定价与支持（12%）。

详细任务说明以考试指南为准；本大纲对应原始知识库结构。

## 学习计划

1. 阅读官方 CLF-C02 考试指南并记录任务说明。
2. 复习本知识库的基础 runbook：[云计算基础](../../foundations-cloud-computing/README_ZH.md)、[共担责任模型](../../shared-responsibility-model/README_ZH.md)、[Well-Architected Framework](../../well-architected/README_ZH.md)、[定价模式](../../pricing-models/README_ZH.md)和[AWS 生态](../../aws-ecosystem/README_ZH.md)。
3. 在本知识库中动手练习服务 runbook（EC2、S3、Lambda、IAM、VPC、RDS、DynamoDB 等）。
4. 在 AWS Skill Builder 做官方练习题，复习薄弱领域。
5. 报考前重新查看考试指南；AWS 会随时间更新考试范围。
