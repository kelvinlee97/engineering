# AWS 云角色能力（Competencies）- 学习大纲

> 事实核对时间（对照 AWS 官方文档）：2026-08-19

## 概述

AWS Partner competencies 验证 AWS 合作伙伴在特定解决方案领域（例如 DevOps、安全、数据与分析、迁移、SaaS）具备经 AWS 验证的专业能力和客户成功经验。对个人而言，AWS Certifications 是验证云实践者、架构师、开发者和运维工程师等角色技能对应的认证。

## 核心概念

- **AWS Partner competencies**：验证合作伙伴能力的项目；合作伙伴通过 AWS 验证的客户案例、技术要求和客户成功来证明能力。
- **能力等级**：合作伙伴在同一 competency 内根据验证深度达到 Select、Advanced、Specialty 等等级。
- **AWS Certifications**：基于角色和专业方向的认证（Cloud Practitioner、Solutions Architect、Developer、SysOps Administrator、DevOps Engineer、Security、Machine Learning、Networking、Database 等），验证个人技能。
- **AWS Training 与 Skill Builder**：与认证考试和岗位角色对齐的官方学习路径。

## 如何准备（个人路径）

1. 为你的角色选择认证（先 Cloud Practitioner，再助理级认证）。
2. 阅读目标考试的官方考试指南（见本知识库的 [Cloud Practitioner 大纲](../cloud-practitioner/README_ZH.md) 等认证大纲）。
3. 在自己的 AWS 账户中用本知识库的服务 runbook 积累动手经验。
4. 使用 AWS Skill Builder 官方练习题和课程。
5. 报考前重新查看考试指南；AWS 会随时间更新考试范围。

## 最佳实践

- 认证匹配实际角色：架构师考设计、开发者考构建、DevOps/SysOps 考运维。
- 认证结合动手项目；证书本身不能代替生产经验。
- 合作伙伴组织将团队认证与所追求的能力领域对齐。
- 按时完成再认证（通常每三年）。
