# AWS Competencies for Cloud Roles - Study Outline

> Facts verified against official AWS documentation: 2026-08-19

## Overview

AWS Partner competencies validate that an AWS Partner has demonstrated technical expertise and proven customer success in a specific solution area (for example, DevOps, Security, Data & Analytics, Migration, SaaS). For individuals, AWS Certifications are the corresponding credential that validates cloud skills for roles such as cloud practitioner, architect, developer, and operations engineer.

## Key concepts

- **AWS Partner competencies**: programs that validate partner capabilities in solution areas; partners demonstrate expertise through AWS-validated references, technical requirements, and customer success.
- **Competency levels**: partners achieve levels such as Select, Advanced, and Specialty within a competency based on validated depth.
- **AWS Certifications**: role-based and specialty credentials (Cloud Practitioner, Solutions Architect, Developer, SysOps Administrator, DevOps Engineer, Security, Machine Learning, Networking, Database, etc.) that validate individual skills.
- **AWS Training and Skill Builder**: official learning paths aligned to certification exams and job roles.

## How to prepare (individual path)

1. Choose the certification for your role (start with Cloud Practitioner, then associate-level certifications).
2. Read the official exam guide for your target exam (see the [Cloud Practitioner outline](../cloud-practitioner/README.md) and other certification outlines in this knowledge base).
3. Build hands-on experience with the service runbooks in this knowledge base in your own AWS account.
4. Use AWS Skill Builder official practice questions and courses.
5. Recheck the exam guide before booking; AWS updates exam scope over time.

## Best practices

- Match certification to your actual role: architect for design, developer for building, DevOps/SysOps for operations.
- Combine certifications with hands-on projects; credentials alone are not proof of production experience.
- For partner organizations, align team certifications with the competency area you are pursuing.
- Keep certifications current with recertification requirements (typically every three years).
