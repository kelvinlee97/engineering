# 安全与发布

这个公开仓库只保存重建环境的说明，绝不保存私人电脑状态。

## 发布阻断项

出现以下任一情况都不能发布：

- 确认存在凭据、私钥、云配置、公司信息或私人机器路径；
- 存在 Critical 或 High 安全发现；
- Medium 发现尚未修复，也没有明确记录接受理由；
- 安装器可能删除已验证临时目录或受管理目标以外的内容；
- 稳定远程执行 URL 没有固定版本；
- 备份、幂等、卸载或配置验证测试失败。

## 审查顺序

1. 运行 `./test/run.zsh`。
2. 使用 `zsh -n` 解析所有 Shell 文件并审查静态分析结果。
3. 扫描工作树和完整 Git 历史中的密钥与敏感文件名。
4. 检查图片像素、终端可见文字和元数据。
5. 审查依赖来源、Homebrew 名称、固定的 Homebrew commit 与发布 URL。
6. 完成仓库安全扫描并记录报告和覆盖缺口。
7. 提交前检查最终 Git diff。
8. 只有人工确认后才能创建签名且不可移动的版本标签。

## 绝不能发布的数据

- API Token、密码、私钥、证书、`.env` 或 Shell 历史
- AWS Profile、Account ID、kubeconfig、集群名称、SSH 目标或内部域名
- 公司/客户代码、日志、工单、主机名、路径或截图
- 个人 Git signing key 或 GitHub 登录状态

## 发布证据

记录 commit SHA、签名标签、验证日期、测试 macOS 版本、硬件架构、工具版本、测试结果、安全扫描覆盖和已接受限制。已有设备测试不能改写成全新设备测试。
