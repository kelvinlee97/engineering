# WeData3 插件

WeData MCP 服务器集成插件，提供完整的 MCP 工具管理功能。

## 功能特性

- **MCP 工具发现** - 自动发现可用的 MCP 服务器和工具
- **工具配置管理** - 轻松添加和管理 MCP 工具到代理配置
- **本地开发支持** - 提供本地 MCP 服务器示例和开发指南
- **部署管理** - WeData 平台部署配置和故障排除
- **快速开始** - 简化的入门指南和最佳实践

## 模块说明

### add-tools
添加 MCP 服务器工具到 WeData 代理配置，支持 URL 和路径配置。

### discover-tools
发现工作空间中可用的 MCP 服务器，提供工具列表和连接信息。

### modify-agent
修改 WeData 代理配置，支持运行时参数调整和优化。

### wedata-deploy
WeData 平台部署管理，包含配置选项、日志指南和故障排除。

### wedata-local-mcp-example
本地 MCP 服务器开发示例，提供模板代码和最佳实践。

### wedata-quickstart
快速开始指南，帮助用户快速上手 WeData MCP 集成。

## 安装使用

```bash
/plugin install wedata3
```
