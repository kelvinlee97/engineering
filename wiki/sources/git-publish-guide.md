A beginner guide in this repository, `Git/publish-to-github/README.md`, to publishing safely: edit, inspect, test, commit, push a branch, open a pull request, merge. A commit is not published until pushed, and a pushed branch does not change `main` until merged.[^git-publish-guide] See [GitHub pull request workflow](../engineering/git/branches-and-pull-requests.md#github-pull-request-workflow).
