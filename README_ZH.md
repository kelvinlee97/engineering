## 内容组织原则

- 保留可复用、主题明确且适合公开仓库的工程资源。
- 优先采用第一手资料或官方来源支持的信息。
- 确保文档与当前实际行为一致，并明确区分个人理解。
- 不保存凭据、公司或客户源码、机密数据、会话历史、缓存或机器专属信息。

## 语言约定

- `README.md` 是默认的英文入口。
- `README_ZH.md` 是对应的中文版本。
- 中英文版本应保持相同的结构、链接和事实范围。
